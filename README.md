# Vikora — личный AI-помощник рекрутера

**Актуальная тестовая сборка:** Vikora 1.4 RC4 для Windows 11.

### Исправление запуска (RC4)

После первого RC3 установщик показывал ошибку `Unable to configure formatter 'default'`. Причина: библиотека Uvicorn пыталась использовать консольные потоки вывода внутри Windows-приложения без консоли. В RC4 конфигурация консольного логирования отключена, а при ошибках создаётся отдельный диагностический файл.

В состав RC4 включён собственный логотип Vikora: значок приложения, установщика и вкладки браузера.

**Успешная Windows-сборка и тестирование:** [GitHub Actions, запуск №10](https://github.com/VandR-Media/Vikora/actions/runs/45056657614). Полученный файл: `Vikora_Setup_1.4.0-rc4.exe`.

[Скачать архив сборки из GitHub Actions](https://github.com/VandR-Media/Vikora/actions/runs/45056657614/artifacts/14767881559) (GitHub может попросить войти в аккаунт).

SHA-256 установщика: `68dcf75c2b910afd45bc550915490547901d5e26f1704a9f83853807e2252eb9`.

### Как установить

1. Скачайте `Vikora_Setup_1.4.0-rc4.exe` и убедитесь, что он получен из проверенного источника.
2. Закройте предыдущую Vikora, если она открыта.
3. Запустите новый установщик и установите его **поверх** RC3 — удалять текущие данные вручную не нужно.
4. Откройте ярлык Vikora на рабочем столе.
5. Если SmartScreen покажет предупреждение о неизвестном издателе, сначала проверьте происхождение установщика и контрольную сумму. Не отключайте Windows Defender ради запуска.

Если программа снова не откроется, посмотрите диагностический файл `%LOCALAPPDATA%\Vikora\vikora_startup_error.log`. Перед отправкой лога кому-либо проверьте его на наличие личных данных.

### Безопасность

- Vikora — **тестовая версия**. Пока не загружайте реальные персональные данные кандидатов.
- Данные сохраняются в `%LOCALAPPDATA%\Vikora` отдельно от установленных файлов. Не удаляйте эту папку.
- AI-модель Qwen и доступ к hh.ru / API провайдерам в установщик не включены; их необходимо подключить отдельно.
- Установщик не подписан цифровой подписью, поэтому репутационная защита SmartScreen может показывать предупреждение.
- Сам репозиторий сейчас **публичный**. Не загружайте сюда реальные резюме, ключи API или резервные копии.

### Для разработчика

Исходный архив RC3 зафиксирован по SHA-256. Сценарий `.github/workflows/build-windows.yml` применяет проверенное исправление `packaging/fix_rc4.py`, восстанавливает иконку из `branding/vikora_logo_png.base64`, запускает тесты, PyInstaller, Inno Setup, smoke-test и проверку переустановки.
