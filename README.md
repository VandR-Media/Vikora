# Vikora — персональный AI-помощник рекрутера

**Версия:** 1.4 RC3 с исправлениями совместимости Windows. Исходный код загружен, Windows-установщик собирается автоматически.

## Где скачать установщик

1. Откройте [**Vikora → Actions**](https://github.com/VandR-Media/Vikora/actions/workflows/build-windows.yml).
2. Выберите последний запуск «Vikora — собрать установщик Windows».
3. Если у запуска **зелёная галочка**, откройте его и в разделе **Artifacts** скачайте `vikora-windows-installer-test`.
4. Распакуйте скачанный ZIP: внутри установочный `Vikora_Setup_1.4.0-rc3.exe` и файл `SHA256SUMS.txt`.

**Если запуск завершился ошибкой, не устанавливайте ничего.** Проверяем ошибки сборки до использования приложения.

## Как устроено

Vikora предназначена для одного пользователя на ноутбуке с Windows 11. Включает вакансии, карточки кандидатов, импорт до 50 резюме, профессиональный словарь, оценки ИИ, hh.ru и резервное копирование. Отдельный сервер не нужен. Облачные API и локальная модель настраиваются отдельно.

- Пока программа не прошла испытания на вашем Windows-компьютере, используйте только **вымышленные резюме**.
- **Не загружайте** в GitHub реальные резюме, пароли или API-ключи.
- Репозиторий публичный. Если предпочитаете закрыть исходники, измените его видимость в настройках GitHub.
- Установщик пока без цифровой подписи и может вызывать предупреждения Windows SmartScreen.
- Личные данные и настройки должны храниться в `%LOCALAPPDATA%\\Vikora`.
