# Vikora — личный AI-помощник рекрутера

**Текущая версия:** 1.4 RC3 (тестовая, ещё не проверена на ноутбуке). Проект рассчитан на Windows 11 и одного HR-специалиста.

## Получение Windows-установщика без программирования

1. В чате ChatGPT скачайте файл **[Vikora_v1.4_RC3_Windows_ReleaseKit_source.zip](https://chatgpt.com/)**. *Ссылка ведёт к ChatGPT; сам файл приложен к нашему разговору.*
2. Вернитесь в этот репозиторий, нажмите **Add file → Upload files**.
3. Перетащите **именно скачанный ZIP, не распаковывая**. Название файла должно быть `Vikora_v1.4_RC3_Windows_ReleaseKit_source.zip`.
4. Нажмите **Commit changes** (подтвердить загрузку).
5. Откройте вкладку [**Actions**](https://github.com/VandR-Media/Vikora/actions/workflows/build-windows.yml).
6. Откройте последний запуск **«Vikora — собрать установщик Windows»**. Если рядом зелёная галочка, внизу страницы будет раздел **Artifacts**. Скачайте `vikora-windows-installer-test`.
7. Распакуйте скачанный архив. Внутри должен быть установочный `Vikora_Setup_*.exe` и файл `SHA256SUMS.txt` для проверки.

Если сборка завершилась с красным крестиком, **не пытайтесь устанавливать программу**. Вернитесь в чат и пришлите ссылку на запуск — разберём причину.

Сценарий Windows-сборки автоматически проверяет SHA-256 исходного архива, выполняет тесты, упаковывает приложение, проверяет запуск `.exe`, установку, переустановку и сохранность синтетических данных. **Успешная сборка не заменяет проверку на вашем настоящем ноутбуке.**

## Безопасность

- **Репозиторий сейчас публичный.** Перед публикацией исходников можно сделать его приватным: **Settings → General → Danger Zone → Change repository visibility → Make private**. Если оставите публичным, ZIP с исходниками смогут скачать другие люди.
- **Никогда не загружайте сюда реальные резюме**, пароли, токены API, файлы `.env`, резервные копии или персональную базу кандидатов.
- Встроенные AI-модели не включены в установщик. Доступ к hh.ru и облачным сервисам требует отдельной настройки и проверки.
- Установщик пока не имеет цифровой подписи; Windows SmartScreen может показать предупреждение. Не обходите предупреждения без проверки происхождения файла.
- Данные реальной программы должны храниться в профиле Windows (`%LOCALAPPDATA%\Vikora`), а не в папке исходников.
- **Пока используйте только вымышленные резюме.** Для обработки персональных данных ещё требуется приёмочное испытание безопасности.
